# Home artwork

Four owner-supplied ChatGPT images, converted to RGB WebP with proportions preserved and metadata omitted. Landscape artwork has 640/1280px variants; square artwork has 400/800px variants. Quality 80, Lanczos resize. Original supplied PNGs remain untouched outside the repository.

- family-together: landscape family scene for public hero.
- family-connections: family tree for family cards.
- family-everyday: shared everyday moments for public feature section.
- family-vision: owner-supplied concept with embedded feature labels; displayed with a future-vision caption, not as a current-feature promise.

Use intrinsic dimensions, responsive srcset/sizes and lazy loading below the fold. These illustrations are not photographs of application users.
